# Installation

1. Clone this repository
2. Install Node.js 22 or newer and FFmpeg
3. Install the required packages by running `npm install`
4. Put your OpenAI API key into the `.env` file
    - Example file: [.env-example](https://github.com/askrella/whatsapp-chatgpt/blob/master/.env-example)
    - You can obtain an API key [here](https://platform.openai.com/account/api-keys)
5. Run the bot using `npm start`
6. Scan the QR code with WhatsApp (link a device)
7. Now you're ready to go! People can send you messages, and the bot will respond to them
